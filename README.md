# Love Vote

Node.js + Express 기반의 시간대별 투표 앱입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 설정

투표 참여자와 관리자 비밀번호는 `.env`에서 관리합니다.

```dotenv
boy = ["김상기", "제이든"]
girl = ["이한나", "엘리"]
admin_password = "관리자 비밀번호"
```

후보자와 투표 데이터는 서버가 자동 생성하는 SQLite DB `data/love-vote.sqlite3`에 저장됩니다. 최초 실행 시 기존 `data/votes.json`이 있으면 자동으로 이전합니다. `.env`의 후보자 목록은 DB 초기 데이터로만 사용되며, 이후 후보자 추가·삭제는 DB에 저장됩니다. 서버는 한국시간(Asia/Seoul) 기준으로 매 정시 라운드를 바꾸며, 등록된 참여자가 투표를 완료하면 해당 시간대 결과가 기록됩니다. 남자 참여자는 여자 후보만, 여자 참여자는 남자 후보만 선택할 수 있고 관리자와 스태프는 결과만 확인할 수 있습니다.

참여자가 입장하면 해당 이름은 활성 세션으로 잠기며, 다른 사용자가 같은 이름으로 입장할 수 없습니다. 정상적으로 나가거나 브라우저를 종료하면 세션이 해제되고, 연결이 끊긴 경우 30분 후 자동 해제됩니다.

참여자와 스태프 세션은 서버 세션이 유지되는 동안 사용할 수 있습니다. 서버 세션이 만료되거나 로그아웃·브라우저 종료·관리자 강제 종료가 발생하면 초기 화면으로 돌아갑니다.

스태프는 남자·여자 후보 전체를 읽기 전용으로 확인할 수 있습니다. 관리자는 `admin_password`와 일치하는 비밀번호로 입장한 뒤 참여상태 전체 해제, 개별 참여자 강퇴, 남자·여자 후보 추가/삭제, 시간대별 투표 초기화를 사용할 수 있습니다.
관리자 화면의 참여자 목록에서 특정 참여자의 세션만 강제 종료할 수도 있으며, 시간대를 선택하면 참여자별 투표 완료 여부를 확인할 수 있습니다. 투표 종료 후 결과 archive에 표시할 상위 순위 인원 수와 후보자 설정은 SQLite DB에 보존됩니다.
관리자 도구에서 관리자 세션 유지 시간을 1~1,440분 범위로 설정할 수 있으며, 설정값은 SQLite DB에 보존됩니다. 설정을 저장하면 현재 관리자 세션에도 즉시 적용됩니다.
