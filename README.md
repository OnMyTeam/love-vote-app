# Love Vote

Node.js + Express 기반의 시간대별 투표 앱입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 설정

투표 참여자와 관리자 비밀번호는 `.env`에서 관리합니다.

```dotenv
boy = ["김상기", "제이든"]
girl = ["이한나", "엘리"]
admin_password = "관리자 비밀번호"
```

투표 데이터는 서버가 자동 생성하는 `data/votes.json`에 저장됩니다. 서버의 현지 시간 기준으로 매 정시 라운드가 바뀌며, 등록된 참여자가 투표를 완료하면 해당 시간대 결과가 기록됩니다. 남자 참여자는 여자 후보만, 여자 참여자는 남자 후보만 선택할 수 있고 관리자와 Guest는 결과만 확인할 수 있습니다.

참여자가 입장하면 해당 이름은 활성 세션으로 잠기며, 다른 사용자가 같은 이름으로 입장할 수 없습니다. 정상적으로 나가면 즉시 잠금이 해제되고, 비정상 종료 시 10분 후 자동 해제됩니다.

참여자와 Guest 세션은 브라우저 새로고침 시에도 같은 탭의 세션이 복원됩니다. 서버 세션이 만료되거나 관리자에 의해 강제 종료된 경우에는 자동으로 초기 화면으로 돌아갑니다.

Guest는 남자·여자 후보 전체를 읽기 전용으로 확인할 수 있습니다. 관리자는 `admin_password`와 일치하는 비밀번호로 입장한 뒤 참여상태 전체 해제, 개별 참여자 강퇴, 남자·여자 후보 추가/삭제, 시간대별 투표 초기화를 사용할 수 있습니다.
관리자 화면의 참여자 목록에서 특정 참여자의 세션만 강제 종료할 수도 있으며, 투표 종료 후 결과 archive에 표시할 상위 순위 인원 수를 저장할 수 있습니다. 표시 인원 설정은 `data/votes.json`에 보존됩니다.
